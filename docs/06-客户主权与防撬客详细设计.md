# 06 · 客户主权与防撬客详细设计（技术与机制）

> 本章把 02 章的归属规则落到**技术实现层**：数据隔离、联系方式托管（虚拟号）、AI 数据使用边界、审计日志、平台公约。目标是让"绝不撬客"可验证、可追责，而非口头承诺。

---

## 1. 多租户数据隔离

### 1.1 隔离模型
- **逻辑隔离 + 行级权限**：核心库共用，但每条客户/货源/画像数据带 `owner_merchant_id` 与 `visibility`。
- **统一访问网关**：所有数据读取经过权限中间件，自动注入过滤条件：
```
WHERE (owner_merchant_id = :current_merchant
       OR visibility = 'public'
       OR (visibility = 'assigned' AND :current_merchant IN assigned_list))
```
- 战略客户 / private 数据：除归属商家外，任何接口、任何角色（含撮合服务）都查询不到。

### 1.2 防越权
- 服务间调用携带 `merchant_context`，撮合服务只能拉取 `visibility=public` 的候选集，物理上拿不到私域数据。
- AI/分析服务走**独立只读视图**，视图层已剥离敏感字段（联系方式、底价）。

---

## 2. 联系方式托管（虚拟号 / 站内通道）

核心：**真实电话/微信永不暴露给第三方，竞争对手无法绕过平台直接联系你的客户。**

### 2.1 机制
| 场景 | 通道 |
|---|---|
| 商家 ↔ 自己的私域客户 | 可见真实联系方式（或仍走平台通道，按商家设置） |
| 公域撮合双方（成交前） | **虚拟中间号 + 站内 IM**，双方看不到对方真实号码 |
| 任何第三方 | 永远拿不到 private/战略客户的真实联系方式 |

### 2.2 虚拟号映射
- `contact.phone_token` 存映射 ID，真实号码加密存于独立保险库（KMS 加密、最小权限访问）。
- 拨打/发短信经隐私号网关路由；可设有效期、可一键解绑，离开撮合场景即失效。

### 2.3 防泄漏细节
- 卡片、消息、导出文件一律展示脱敏号（如 138****0000）。
- 禁止导出含真实联系方式的客户表给非归属方；导出行为记入审计。

## 3. AI 数据使用边界

防止"用 A 的客户数据喂模型，再把 A 的客户引流给 B"。

1. **训练数据匿名化/聚合**：模型训练只用脱敏、聚合后的数据，禁止包含可定位到"某商家的某客户"的特征。
2. **能力域隔离**：运营类 AI（补货提醒、销售副驾驶）`scope=owner_only`，只对归属商家开放，不跨商家。
3. **撮合只用公域**：撮合模型的候选与特征仅来自公域池。
4. **行情聚合脱敏**：行情卡片用聚合均价，不暴露单笔成交与具体对手方。
5. **可解释**：推荐/撮合结果保留来源说明，便于审计"这条推荐是否动用了不该用的数据"。

## 4. 审计与透明（信任来自可验证）

### 4.1 审计日志 `access_audit`
| 字段 | 说明 |
|---|---|
| audit_id | 主键 |
| actor_merchant_id | 访问方商家 |
| target_customer_id | 被访问客户 |
| action | view/contact/distribute/claim/export |
| channel | 接口/页面 |
| result | allowed/denied |
| reason | 规则命中说明 |
| occurred_at | 时间 |

### 4.2 给商家的透明看板
- 「我的客户被谁看过 / 有没有被分发」记录可自助查询。
- 归属变更历史：谁在何时因何规则获得/失去某客户（与 02 章规则引擎联动）。
- 异常告警：若出现疑似越权访问，主动通知商家。

---

## 5. 商业模式对齐（从动机上消除撬客）

| 原则 | 说明 |
|---|---|
| 平台不自营、不下场交易 | 不自己买卖钢材，消除"既当裁判又当运动员" |
| 收费不依赖卖客户 | 靠 SaaS 订阅 + 增值服务（行情/风控/账期金融/AI 助手）+ 公域成交佣金 |
| 防撬客写入公开公约 | 白纸黑字、违规可追责 |
| 可审计 | 商家能自查平台是否守约 |

---

## 6. 平台公约（对外条款要点）

写入用户协议与产品界面，形成可执行承诺：
1. 商家私域客户的需求**不向第三方分发**。
2. 高价值客户可**专属锁定**，永不入公海、永不被撮合。
3. 客户联系方式**加密托管**，第三方无法获取。
4. 平台**不自营交易**，不与商家争抢客户。
5. 商家可**随时查询**客户被访问与分发记录。
6. 违反上述条款的，商家可投诉并追责。

---

## 7. 战略客户"保险柜"清单（高价值客户加固）

对 `is_strategic=true` 的客户，叠加全部保护：
- ✅ 永久绑定，规则引擎跳过一切掉保逻辑（02 章）。
- ✅ visibility 强制 private，任何撮合/外拓都排除（02/03 章）。
- ✅ 联系方式强制平台托管脱敏（本章第 2 节）。
- ✅ 运营 AI 仅归属商家可用（本章第 3 节）。
- ✅ 任何对其的访问尝试均记审计并可告警（本章第 4 节）。
- ✅ 同一客户只能被一家设为战略（互斥，先到先得 + 客户可申诉）。
