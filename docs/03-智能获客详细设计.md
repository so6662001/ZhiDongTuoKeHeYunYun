# 03 · 智能获客详细设计

> 获客分为「平台内激活/撮合」与「平台外拉新」。钢铁圈优先做前者——把已有供需数据变成线索，几乎零边际成本。**所有撮合只作用于公域流量（详见 02 章）。**

---

## 1. 智能供需撮合（核心引擎）

### 1.1 触发时机
- 卖方上架/更新 `listing`（visibility=public）→ 反向匹配公域买方需求。
- 买方发布 `demand`（is_public=true 或无私域归属）→ 正向匹配卖方货源。
- 定时批处理：每日扫描"高意图未成交"的供需，重新撮合。

### 1.2 匹配与排序（先规则后模型）

**第一步：硬过滤（必须全部满足）**
- 品种、规格一致或兼容（建立规格兼容表，如 Φ20 可替代部分 Φ22 需求需标注）；
- 数量满足（卖方可售 ≥ 买方需求下限，或支持拼单）；
- 区域可达（仓库区域与收货区域物流半径合理）；
- **归属校验**：需求无私域归属或为公域；卖方货源 visibility=public。

**第二步：评分排序**（候选匹配打分，取 Top-N 推送）
```
match_score =
    w1 * 价格匹配度(target_price vs listing.price)
  + w2 * 区域邻近度(物流成本反比)
  + w3 * 历史成交契合度(双方历史成交品种/规格重合)
  + w4 * 信用与履约(卖方信用分、买方回款表现)
  + w5 * 时效紧迫度(demand.urgency, listing 库龄)
  - p1 * 重复打扰惩罚(近期已推送过该对)
```
权重 `w*` 可配置；冷启动用经验权重，数据充足后用成交反馈训练排序模型（LTR）。

### 1.3 推送与触达
- **多通道**：站内消息 + 微信卡片 + 短信（按 06 章脱敏通道）。
- **卡片内容**：品种规格、可售吨位、参考价、仓库区域、账期可谈、一键询价按钮。
- **节流**：同一买卖对推送有冷却期；单用户每日推送条数上限，避免骚扰。

### 1.4 场景（带数字）
> 河北批发商上架 500 吨 HRB400E Φ20，public，仓库石家庄，报价 X 元/吨可议 →
> 系统在公域找出近 30 天询过该规格、收货地在华北、信用正常的 12 家买方 →
> match_score 排序取 Top 8 推送微信卡片 → 3 家点开、2 家发起询价 → 进入转化链路（详见 05 章）。

## 2. AI 线索评分与外拓（拉新/激活）

### 2.1 线索分级
对注册未活跃企业打分，分 高潜 / 沉睡 / 无效：
```
lead_score =
    a1 * 企业规模与品种匹配度(与平台主供给契合)
  + a2 * 行为活跃信号(注册后浏览/搜索深度)
  + a3 * 区域供需热度(所在区域平台供需密度)
  + a4 * 资质完整度
```
### 2.2 分配与跟进
- 高潜 → 分配给业务员或 AI 销售（详见 04 章），附**话术建议**：主推品种、切入价位、可给账期。
- 沉睡 → 进入自动化唤醒序列（行情/低价好货）。
- 无效 → 低频维护，节省资源。

## 3. "行情钩子"获客（最低成本裂变）

### 3.1 内容生成
平台每早自动生成区域行情卡片：
- 主流品种（螺纹/热卷等）当日价格 + 涨跌幅 + 简短信号（"窄幅震荡""华东走强"）。
- 数据来源：平台成交均价 + 公开市场行情，做聚合（不泄露单笔成交）。

### 3.2 裂变路径
```
用户一键转发卡片到客户微信群
   → 群内非平台用户点开卡片(带来源标识)
   → 落地页提供"查看本地完整报价/试用"
   → 留资/注册 → 进入线索评分(第2节)
```
### 3.3 增长杠杆
- 转发激励：转发可解锁更细行情/专属优价。
- 卡片埋追踪码，归因到"哪个老用户带来新客"，便于做转介奖励。

---

## 4. 与客户主权的关系（务必遵守）

- 撮合候选只来自**公域**：私域客户的需求绝不进撮合池。
- 推送给卖方时，公域买方信息按需脱敏展示，成交后才按归属规则绑定（详见 02 章）。
- 战略客户、private 可见性的客户/货源，**完全不参与任何撮合与外拓**。

---

## 5. 关键指标
- 撮合推送点击率、询价转化率、撮合促成成交数与成交额。
- 线索：高潜线索占比、线索→注册→首单转化率。
- 行情钩子：卡片分享数、分享带来新客数、转介成本。
