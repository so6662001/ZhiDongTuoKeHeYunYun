# 04 · 智能客户运营详细设计

> 运营本质：用变化（价格、库存、账期、政策）持续制造高质量触达，把客户养熟、提复购。**所有运营能力只服务于客户的归属商家**——平台用 AI 帮你服务好你自己的客户。

---

## 1. 客户分层模型

### 1.1 价值分层（RFM 改造版，适配钢铁）
| 维度 | 含义 | 钢铁口径 |
|---|---|---|
| R Recency | 最近一次成交距今 | 越近越好 |
| F Frequency | 成交频次 | 复购次数/月 |
| M Monetary | 成交贡献 | 成交额 × 毛利 |
| C Credit | 回款表现 | 账期回款及时率（钢铁特有，权重高） |

价值分：`value_score = f(R, F, M, C)` → 分 高/中/低 价值。

### 1.2 生命周期阶段
```
新客 ──首单──▶ 活跃复购 ──频次下降──▶ 沉睡 ──长期无互动──▶ 流失风险/流失
```
按"价值 × 阶段"组成 4×N 矩阵，每格配差异化策略。

| 阶段 | 策略要点 |
|---|---|
| 新客 | 7 天内推主营品种行情 + 1 次专属优价/优账期，促首单 |
| 活跃 | 按复购周期，在"该补货"前主动推同规格货源 |
| 沉睡 | 价格异动/低价好货唤醒 |
| 流失风险 | 识别"频次下降+回款变慢"，预警业务员人工介入 |

## 2. 触发器引擎（运营的心脏）

运营自动化由"事件/条件 → 动作"的触发器驱动。核心触发器：

| 触发器 | 触发条件 | 动作 |
|---|---|---|
| 智能补货提醒 | now - 上次采购 > 复购周期 × 1.2 且无新订单 | 推"常采规格今日到货+价格" + 提醒业务员回访 |
| 价格异动触达 | 客户关注品种价格日变动超阈值（如 ±50 元/吨） | 给"关注该品种且近期未下单"客户推涨跌提示 |
| 库存机会提醒 | 归属商家有匹配该客户偏好的新货源 | 推"专属好货"卡片 |
| 账期到期提醒 | 客户账期临近到期 | 提醒商家催收 + 提示客户续单优惠 |
| 流失预警 | value_score 下降 + R 拉长 + 回款变慢 | 生成预警工单给业务员 |
| 生日/纪念/政策 | 关键时间节点、行业政策变动 | 关怀触达，维系关系 |

### 2.1 触发器配置结构（示例）
```json
{
  "trigger_id": "restock_reminder",
  "scope": "owner_only",            // 仅归属商家的客户
  "condition": "days_since_last_order > repurchase_cycle * 1.2 AND no_open_order",
  "action": { "type": "push", "channel": ["wechat","sms"], "template": "restock_v1" },
  "throttle": { "per_customer_per_day": 1, "cooldown_days": 3 },
  "approval": "auto_or_sales_confirm"  // 涉及报价/账期则需人工确认
}
```

### 2.2 触达治理
- **频控**：单客户每日/每周触达上限，跨触发器统一计算，避免轰炸。
- **静默时段**：夜间不发短信。
- **降噪**：同一客户多个触发器命中时按优先级合并为一条。
- **效果回流**：记录每次触达的打开/回应/成交，反哺触发器阈值与文案优化。

## 3. AI 销售副驾驶（放大业务员产能）

定位：业务员的助手，不替代人做决策。

### 3.1 能力清单
1. **客户简报**：进入某客户时，自动汇总画像、上次聊到哪、当前意图、推荐下一步动作。
2. **话术生成**：按客户画像与当前行情生成个性化报价话术、跟进话术、催收话术。
3. **下一步动作建议**：如"该客户复购周期到，建议今天推 Φ20 螺纹并给 7 天账期"。
4. **自动记录**：把 IM/通话要点自动结构化写回 CRM，减少手工录入。
5. **每日工作清单**：按价值与紧迫度给业务员排出"今天该联系谁、为什么、说什么"。

### 3.2 人机协作边界
- AI 出建议（报价区间、账期、推荐货源）→ **业务员/客户确认**后才生效。
- 涉及金额、账期等敏感动作必须人工确认（与 05 章风控联动）。

### 3.3 场景（带数字）
> 门零客户平均每 18 天采购一次螺纹，系统监测到已 22 天未下单 →
> 触发"智能补货提醒"：给客户推"常采 HRB400E Φ20 今日到货 + 价格" →
> 同时在业务员每日清单置顶该客户，附话术与"可给 7 天账期"建议 →
> 业务员一键发送 + 电话回访 → 客户回单。

## 4. 与数据底座/归属机制的衔接
- 分层与触发依赖 01 章的画像与标签（复购周期、价格敏感度、活跃度、价值分）。
- 所有触达对象限定为触发器 `scope=owner_only` 的归属客户；战略客户的运营完全私有（详见 02/06 章）。

---

## 5. 关键指标
- 复购率、月活、沉睡唤醒率、流失预警命中率。
- AI 触达打开率/回应率/促成成交率。
- 业务员人均有效跟进客户数、人工录入耗时下降幅度。
